Почему старый подход ломается

Лидген чаще умирает не на отправке, а на качестве входа

Обычно

  • ICP описан слишком широко
  • источники дают красивые, но пустые строки
  • персонализация придумывается
  • правки остаются в чате и забываются
  • масштабирование начинается до review

В AI LeadGen OS

  • один campaign profile на batch
  • evidence перед score
  • good / maybe / bad с причинами
  • Memory Patch вместо "запомни"
  • outreach только после human approval
Что собираем

Не папку с промптами, а операционную систему процесса

Template repo - это практический актив внутри курса. Он задаёт структуру, по которой агент перестаёт импровизировать.

docs/os

Правила бизнеса

Company, offer, ICP, negative ICP, sources, outreach rules, success criteria и compliance.

memory

Обучение на review

Good/bad examples, learned rules, tone и reply playbook. Правки владельца становятся файлами.

commands

Playbooks

Onboard, find leads, enrich, score, review, learn from feedback, generate outreach, watch inbox.

runs

История кампаний

Каждый batch живёт в отдельной папке: raw, enriched, scored, reviewed, drafts.

Рабочий цикл

От ICP до драфтов без прыжка в спам

01

Define ICP

Формулируем сегмент, сигналы покупки и negative ICP до поиска.

02

Small batch

10-20 лидов из источника. Один batch - один campaign profile.

03

Evidence + scoring

У каждого лида должен быть наблюдаемый факт и why_relevant.

04

Review

Человек размечает good / maybe / bad и объясняет причины.

05

Memory Patch

Фидбек записывается в docs/os и memory, а не остаётся в чате.

06

Outreach drafts

Только approved лиды. Каждое сообщение с approval_required: yes.

FAQ

Самые частые вопросы

Это SaaS?

Нет. Это курс + workspace setup. Ты работаешь в Claude Code / Codex с template repo.

Это просто промпты?

Нет. Commands - только интерфейс. Продукт - структура, review loop, memory, schema и safety gates.

Будут клиенты после курса?

Курс не гарантирует продажи. Он даёт процесс поиска, проверки и подготовки outreach.

Можно сразу отправлять?

Нет. По умолчанию drafts-only. Отправка - отдельный human approval по списку, тексту, каналу и объёму.
