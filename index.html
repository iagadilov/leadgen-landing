FAQ

Коротко по важным вопросам

Это SaaS?

Нет. Это готовый setup, который ты запускаешь в Claude Code / Codex или другой agentic LLM и настраиваешь под нишу.

Это просто template repo?

Нет. Репозиторий - часть продукта. Важное внутри: обучение, логика настройки, scoring, review, Memory Patch и workflow.

По умолчанию нет. Она готовит drafts. Отправка только после human approval по списку, тексту, каналу и объёму.

Нет. Где возможно - ищем контактный путь и decision maker. Но я не обещаю идеальные контакты в каждой нише.
