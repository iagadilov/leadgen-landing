Как работает AI LeadGen OS

ICP → small batch → scoring → review → Memory Patch → outreach drafts

01

Define ICP

Формулируем сегмент, сигналы покупки и negative ICP до поиска.

02

Small batch

10-20 лидов из источника. Один batch - один campaign profile.

03

Evidence + scoring

У каждого лида должен быть наблюдаемый факт и why_relevant.

04

Review

Человек размечает good / maybe / bad и объясняет причины.

05

Memory Patch

Фидбек записывается в docs/os и memory, а не остаётся в чате.

06

Outreach drafts

Только approved лиды. Каждое сообщение с approval_required: yes.

FAQ

Самые частые вопросы

Это SaaS?

Нет. Это курс + workspace setup. Ты работаешь в Claude Code / Codex с template repo.

Это просто промпты?

Нет. Commands - только интерфейс. Продукт - структура, review loop, memory, schema и safety gates.

Будут клиенты после курса?

Курс не гарантирует продажи. Он даёт процесс поиска, проверки и подготовки outreach drafts.

Можно сразу отправлять?

Нет. По умолчанию drafts-only. Отправка - отдельный human approval по списку, тексту, каналу и объёму.

Будут 100% ЛПР?

Нет. Система помогает искать контактные пути и проверять evidence, но не обещает идеальные контакты в каждой нише.

Что выбрать: Course или DFY?

Course - если хочешь собрать сам. DFY - если нужен setup под бизнес и handoff процесса команде.
