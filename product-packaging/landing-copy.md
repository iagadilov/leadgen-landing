## Positioning

AI LeadGen OS - это не SaaS и не курс по промптам.

Это готовый leadgen setup + обучение, которое помогает настроить систему под свою нишу: ICP, источники данных, scoring, review, Memory Patch и outreach drafts.

Почему не SaaS: у всех разные ниши, офферы, источники, гео, каналы и тон. Универсальная кнопка быстро превращается в мусор. Поэтому продукт упакован как настраиваемая система: клиент либо адаптирует её сам, либо берёт DFY-внедрение.

## Two Paths

### 1. Product + Training

Получаешь готовый setup и учишься запускать его у себя.

Внутри:

- setup repo для Claude Code / Codex / agentic LLM;
- обучение, как пользоваться из коробки;
- модули ICP, sources, scoring, review, Memory Patch;
- example run;
- workflow для персональных outreach drafts;
- controlled sending module после approval, дедупа, лимитов и выбора канала.

### 2. Done For You

Ильяс кастомно собирает AI LeadGen OS под бизнес.

Внутри:

- диагностика ниши и оффера;
- кастомный ICP / negative ICP;
- подбор sources и scoring;
- test batch;
- review качества;
- handoff процесса команде;
- связь с Ильясом на этапе внедрения.

## Output

На выходе не просто список компаний, а рабочий leadgen пакет:

- отфильтрованные лиды;
- контакты и контактный путь, где доступны;
- угол захода к каждому лиду;
- персональный outreach draft;
- объяснение, почему лид подходит;
- следующий шаг по лиду.
