# AI LeadGen OS - product positioning

## Что это

AI LeadGen OS - это практический видеокурс по сборке собственного AI LeadGen workspace под нишу.

Студент не просто получает набор промптов. Он собирает рабочую систему, в которой AI-агент помогает описать ICP, найти маленький батч лидов, проверить evidence, засчитать качество, провести review, записать правила в memory и подготовить персональные outreach drafts.

Template repo - это практический актив внутри курса: стартовый workspace для Claude Code / Codex с готовой структурой файлов, playbooks, safety rules и example run. Курс объясняет, как этот workspace адаптировать под свой бизнес и не сломать процесс на первом же батче.

## Чем это НЕ является

- Не SaaS и не личный кабинет с кнопкой "получить клиентов".
- Не один промпт, который сам найдёт ЛПР и продаст.
- Не база готовых лидов.
- Не гарантия продаж.
- Не авторассылка без контроля.
- Не способ обходить лимиты платформ.
- Не замена офферу, продажам и человеческому review.

## Кому подходит

- Владельцам B2B-бизнесов, которым нужны новые клиенты, но они не хотят покупать мусорные базы.
- Агентствам и специалистам, которые продают услуги и хотят системно искать релевантных лидов под свой оффер.
- Фаундерам и AI-builder'ам, которые готовы работать руками вместе с агентом: ревьюить лидов, уточнять ICP, улучшать правила.
- Командам, где есть человек, способный принимать решения по качеству лида и финально апрувить outreach.

## Кому не подходит

- Тем, кто хочет "клиенты на автомате" без участия.
- Тем, кто не готов разбирать good / maybe / bad лидов и объяснять причины.
- Тем, кто хочет массовую рассылку без evidence и персонализации.
- Тем, у кого нет понятного B2B-оффера или минимального чека, который окупает ручной outbound.
- Тем, кто хочет обойти правила платформ или отправлять без human approval.

## Почему это видеокурс, а не просто template repo

Template repo показывает структуру системы, но сам по себе не принимает бизнес-решения за человека.

Курс нужен, чтобы студент понял:

- как описать свой бизнес и ICP так, чтобы агент не искал случайных людей;
- почему "ниша + гео" не является evidence;
- как отделять good лидов от красивого мусора;
- как проводить review и превращать фидбек в Memory Patch;
- почему outreach начинается только после качества батча, а не после парсинга;
- как безопасно масштабировать источник, не повторяя ошибки массовой рассылки.

Продукт - это обучение сборке процесса. Template repo - рабочий каркас, на котором студент тренируется и потом работает.

## Course vs Done For You

**Course / Training** - для тех, кто хочет собрать систему сам.

Студент получает видеоуроки, clean template repo, roadmap, playbooks, example run и safety rules. Результат - свой AI LeadGen workspace под нишу, который можно дальше улучшать через review и memory patches.

**Done For You** - для тех, кто хочет, чтобы систему адаптировали под бизнес/команду.

В этом формате Ильяс разбирает нишу, формирует ICP, делает тестовый батч, настраивает scoring/review/memory, готовит outreach drafts и передаёт команде рабочий процесс.

## Честное обещание результата

После курса человек не получает обещание продаж. Он получает собранный leadgen workspace и понятный процесс:

ICP -> small batch -> evidence -> scoring -> review -> Memory Patch -> outreach drafts -> human approval.

Хороший результат курса - студент умеет запускать маленькие батчи, видеть качество лидов, обучать систему на своих решениях и готовить персональный outreach без хаоса.
