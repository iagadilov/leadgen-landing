# Pricing options - AI LeadGen OS

Цены ниже - текущая лестница упаковки для лендинга.

## 1. AI LeadGen OS

**Формат:** готовый setup + обучение.

Что входит:

- готовый setup repo;
- видео-модули;
- маршрут запуска;
- commands/playbooks;
- docs/os templates;
- memory patch protocol;
- lead schema;
- example run;
- safety rules;
- обновления раннего доступа.

Для кого:

- хочет собрать сам;
- готов работать с Claude Code / Codex;
- готов review-ить лидов и улучшать правила;
- не ждёт DFY-внедрения.

Ограничения:

- без личной настройки под нишу;
- без гарантии качества источников;
- без promise продаж;
- outreach только после human approval.

Цена:

- AI LeadGen OS: 100 000 KZT (≈ $212 / ₽16 400).

Примечание для лендинга: конвертация ориентировочная, оплата фиксируется в тенге.

## 2. OS + связь со мной

**Формат:** setup + обучение + разбор с Ильясом.

Что входит:

- всё из AI LeadGen OS;
- review первого `docs/os/` setup;
- review первого batch;
- комментарии по ICP, negative ICP, evidence и scoring;
- разбор одного Memory Patch;
- рекомендации по next batch.

Для кого:

- хочет собрать сам, но боится ошибиться в первом ICP;
- хочет, чтобы кто-то посмотрел на качество лидов;
- хочет быстрее выйти на рабочий loop.

Ограничения:

- это не DFY;
- Ильяс не делает полный research вместо студента;
- не гарантируются лиды/продажи;
- feedback ограничен заранее заданным объёмом.

Цена:

- OS + связь со мной: 299 000 KZT (≈ $633 / ₽48 900).

## 3. Done For You

**Формат:** внедрение AI LeadGen OS под бизнес/команду.

Что входит:

- диагностика ниши и оффера;
- ICP / negative ICP;
- sources;
- test batch;
- enrichment + scoring;
- review session;
- Memory Patch;
- outreach drafts;
- reply playbook;
- передача workspace;
- team handoff.

Для кого:

- нужен результат быстрее;
- есть команда или бизнес с чеком, где внедрение окупается;
- не хочется самому разбираться в setup;
- нужен test batch перед масштабированием.

Ограничения:

- стартуем с test batch;
- массовую отправку не запускаем без review и approval;
- цена/условия зависят от ниши, источников и глубины внедрения;
- не обещаем продажи.

Цена:

- Done For You: от 1 500 000 KZT (≈ $3 178 / ₽245 500) / заявка.
- Support после внедрения: отдельно.
