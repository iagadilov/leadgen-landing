# Лендинг: Лидген под твою нишу

Промо-лендинг лидген-продукта + форма «заявка на внедрение» → уведомление тебе в Telegram.

## Что внутри
- `index.html` / `styles.css` / `app.js` - сам лендинг (статика, без сборки)
- `api/lead.js` - serverless-функция: принимает форму и шлёт тебе сообщение в Telegram-бота

## Настройка Telegram (один раз, ~2 минуты)
1. В Telegram напиши **@BotFather** → `/newbot` → задай имя → получишь **токен**.
2. Напиши своему новому боту любое сообщение (чтобы он мог тебе писать).
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → найди `"chat":{"id": ЧИСЛО}` → это твой **chat_id**.
4. Впиши оба значения в переменные окружения (см. `.env.example`).

## Запуск локально (с рабочей формой)
```bash
cd landing
cp .env.example .env   # впиши токен и chat_id
vercel dev             # поднимет статику + /api на localhost
```
Открой адрес из вывода, заполни форму - тебе придёт сообщение в Telegram.

> Можно просто открыть `index.html` в браузере, чтобы посмотреть дизайн,
> но форма заработает только под `vercel dev` или после деплоя (нужен `/api`).

## Деплой на Vercel
```bash
cd landing
vercel            # первый раз - привяжет проект
vercel --prod     # прод-деплой
```
Затем в **Vercel → Project → Settings → Environment Variables** добавь
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` и сделай повторный `vercel --prod`.
